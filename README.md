# personal-profile-2.2
CSC584 Personal Profile Web Application

Student Profile Management System
The Student Profile Management System is a web-based application developed to manage student profile information. The system allows users to create, view, update, delete and search student profiles.

Users can enter student information such as Student ID, Name, Programme, Email, Hobbies and Short Self Introduction through a web-based interface. The application processes the information using Java Servlets and displays the profile details through JSP pages.

The system uses JavaBean technology and follows the Model-View-Controller (MVC) architecture to organize the application and improve code reusability and maintainability.

Technologies Used
HTML – Structures the web pages and input forms.
CSS – Styles the application interface.
Bootstrap 5 – Provides responsive layouts and UI components.
Java – Handles the application's backend processing.
Java Servlet – Processes user requests and manages application operations.
JSP (JavaServer Pages) – Displays student profile information.
JavaBean – Represents and manages student profile data.
Apache Derby Database – Stores student profile records.
NetBeans IDE 8.2 – Used for application development.
GlassFish Server 4.1.1 – Used to deploy and run the web application.

System Requirements
Before running the application, ensure that the following software is installed:

NetBeans IDE 8.2

Compatible Java Development Kit (JDK)

GlassFish Server 4.1.1

Apache Derby Database

Web browser (Google Chrome, Microsoft Edge or Firefox)

Installation and Setup Instructions
Step 1: Download the Project

1. Clone or download this project from GitHub.

2. Extract the project folder if downloaded as a ZIP file.

3. Open NetBeans IDE 8.2.

Step 2: Open the Project

1. Open NetBeans IDE.

2. Select File → Open Project.

3. Locate and select the downloaded project folder.

4. Click Open Project.

Step 3: Configure the Server

1. Open the Services tab in NetBeans.

2. Ensure GlassFish Server 4.1.1 is available.

3. Start the GlassFish server.

4. Ensure the project is configured to use GlassFish Server 4.1.1.

Step 4: Configure the Database

1. Start or configure the Apache Derby database.

2. Ensure the required database and connection pool settings are available.

3. Verify that the database connection settings match the project's configuration.

4. Ensure the required student profile table has been created.

Ensure the required database and connection pool settings are available.

Verify that the database connection settings match the project's configuration.

Ensure the required student profile table has been created.

Step 5: Run the Application
1. Right-click the project in NetBeans.

2. Select Clean and Build.

3. Once the build is successful, right-click the project again.

4. Select Run.

5. The application will open in your default web browser.



 Main System Features

Create Profile – Add a new student profile.

View Profiles – Display all registered student profiles.

Search Profile – Search for student profiles using Student ID or Name.

Update Profile – Edit existing student information.

Delete Profile – Remove student profile records from the database.

 Project Purpose

The purpose of this project is to demonstrate the development of a Java-based web application using HTML, CSS, Java Servlets, JSP, JavaBeans and database integration. It provides practical experience in web application development and the implementation of the MVC architecture.
